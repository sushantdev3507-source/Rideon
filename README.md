# RideOn – Car Renting Website (Mini Project)

Files: index.html, style.css, script.js

## Host on Vercel
1. Go to https://vercel.com and sign in (GitHub login works).
2. Upload this folder to a new GitHub repo, then on Vercel click "Add New → Project" and import it.
   (Or install Vercel CLI: `npm i -g vercel`, open this folder in terminal and run `vercel`.)
3. Framework preset: "Other". Click Deploy. You get a link like https://rideon.vercel.app

## Features
- Sign up / Login
- Book Bike, Auto, Mini, Sedan, SUV with live fare estimate
- Rent cars per day
- My Rides history with cancel option
- Data saved in the browser (localStorage)
